# Collection Project

This is a Java project demonstrating various examples from the Java Collection Framework, such as List, Set, Map, and their implementations.

## Features
- Use of ArrayList, LinkedList, HashSet, TreeSet
- Demonstrations of HashMap and TreeMap
- Custom sorting with Comparators
- Practical examples for learning collections
